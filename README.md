# 📊 Sales Analytics Dashboard

A modern and interactive Sales Analytics Dashboard built with **React.js**, **Tailwind CSS**, and **Recharts**. The application allows users to upload CSV sales data, validate it, map columns dynamically, and generate business insights through interactive dashboards and AI-powered predictions.

---

## 🚀 Features

- 📂 Upload CSV sales dataset
- 🔄 Dynamic column mapping
- ✅ Data validation
- 📈 Revenue trend analysis
- 🛍️ Top products analysis
- 🌍 Revenue by region analysis
- 📦 Quantity by product visualization
- 📅 Filter by Date, Product, Category, and Region
- 📊 KPI cards for Revenue, Orders, Quantity, and Discount
- 🤖 AI-based business insights
- 📈 Revenue prediction
- 📄 Generate downloadable sales report
- 📱 Responsive dashboard design
